# 거북섬 어린왕자 AR 보물찾기

9월 12일 시흥 거북섬 행사에서 사용할 수 있는 모바일 우선 웹앱 시안입니다.

## 실행

`index.html`을 웹 서버로 열어 휴대폰에서 접속하세요. 카메라 기능과 설치형 앱(PWA)은 HTTPS 또는 localhost 환경에서만 정상 동작합니다.

## 현장 운영 흐름

1. 현장에 `assets/six-zone-markers.png`의 ZONE 01~06 마커를 각각 인쇄·설치합니다.
2. 참가자가 카메라로 마커를 스캔한 뒤 보물 상자를 열고 메시지를 봅니다.
3. ZONE 01~03은 별빛 스탬프, ZONE 04~06은 장미 스탬프가 지급됩니다.
4. 서로 다른 ZONE 2개를 완료하면 직원 확인용 인증서가 열립니다. 화면을 캡처하거나 ‘인증서 이미지로 저장하기’를 눌러 직원에게 제시하도록 안내합니다.

## 실제 AR 인식 연결 전 확인할 점

현재 버전은 카메라 UX와 전체 미션·스탬프 흐름을 구현한 현장 시연형 웹앱입니다. 인쇄 이미지 자체를 자동 인식해 3D/영상 AR을 띄우려면 MindAR, 8th Wall 등 이미지 타깃 AR 서비스와 행사 전용 HTTPS 주소를 연결해야 합니다. `app.js`의 `selectZone()`이 마커 인식 성공 후 실행할 지점입니다.
